# Customer Behaviour Analysis

## 📌 Overview

This project focuses on analyzing customer behaviour and purchasing patterns to identify meaningful business insights.

The project covers the complete data analytics workflow, starting from data loading and cleaning to SQL analysis, data visualization, dashboard creation, reporting, and presentation.

The main objective is to understand customer behaviour, identify important trends, and present data-driven insights that can support business decision-making.

---

## 📂 Dataset

The project uses a customer-related dataset containing information about customers, purchases, products, demographics, and other relevant attributes.

The dataset was initially loaded and explored using Python and Pandas before performing data cleaning and analysis.

---

## 🔄 Project Steps

### 1. Data Loading

- Loaded the dataset into Python using Pandas.
- Checked the structure and dimensions of the dataset.
- Examined columns, data types, and missing values.

### 2. Exploratory Data Analysis (EDA)

Performed exploratory analysis to understand:

- Customer characteristics
- Purchasing behaviour
- Product preferences
- Sales and revenue patterns
- Customer trends
- Relationships between different variables

### 3. Data Cleaning

The dataset was cleaned and prepared for analysis by:

- Handling missing values
- Checking duplicate records
- Correcting data types
- Handling inconsistent values
- Removing unnecessary data where required
- Preparing the dataset for further analysis

### 4. SQL Analysis

The cleaned data was analyzed using **MySQL**.

SQL queries were used for:

- Aggregation
- Filtering
- Grouping
- Sorting
- Conditional calculations
- Customer analysis
- Product analysis
- Revenue analysis
- Business-related insights

### 5. Data Visualization

Visualizations were created using Python and Power BI to identify patterns and communicate insights effectively.

### 6. Power BI Dashboard

An interactive Power BI dashboard was created to present key business metrics and customer behaviour insights.

The dashboard includes relevant:

- KPIs
- Charts
- Customer analysis
- Product analysis
- Sales/revenue analysis
- Filters and slicers

### 7. Report

A detailed project report was prepared to document:

- Project objectives
- Data preparation
- Analysis performed
- SQL queries
- Key findings
- Business insights
- Dashboard results

### 8. Presentation

A PowerPoint presentation was created using **Gamma** to summarize the project, methodology, dashboard, findings, and recommendations.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/customer-behaviour-analysis.git
```

### 2. Install required Python libraries

```bash
pip install pandas numpy matplotlib jupyter
```

### 3. Open Jupyter Notebook

```bash
jupyter notebook
```

Open the analysis notebook from the `notebooks` folder.

### 4. Run the Python analysis

Run the notebook cells step by step to perform:

- Data loading
- Data cleaning
- EDA
- Visualization
- Analysis

### 5. Run SQL Analysis

Import the dataset into **MySQL** and execute the SQL queries available in the `sql` folder.

### 6. Open Power BI Dashboard

Open the `.pbix` file from the `dashboard` folder using Power BI Desktop.
